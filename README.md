# KH Visit Page Workspace

국가유산 방문 캠페인 `이달의 방문코스` 페이지를 정적으로 옮겨 놓고, 그 위에서 바로 개선 작업을 시작하기 위한 로컬 작업 환경입니다.

## 파일 구성

- `index.html`: 현재 운영 페이지 구조를 따라간 정적 화면
- `styles.css`: 정적 복제 레이아웃과 반응형 스타일
- `script.py`: 로컬 미리보기 서버

## 실행 방법

```bash
python3 script.py
```

브라우저에서 `http://127.0.0.1:8000` 를 열면 됩니다.

## 현재 포함된 것

- 운영 페이지의 텍스트 구조를 반영한 정적 화면
- 원본 이미지 대신 동일 위치의 플레이스홀더 블록
- 모바일 대응 레이아웃
